# NS3

## Product statement

NS3 turns an authorized objective into an executed result that is independently verified, custody-preserved, recoverable, and reported to HUMAN without HUMAN acting as a message relay.

NS3 does not permit a producing agent or runtime to accept its own result.

## Functional core

`HUMAN → MORCH → RORCH → Production → Quality / NTV / IV&V → Custody → MORCH → HUMAN`

- **NightShift contribution:** orchestration, authority, contracts, continuity, routing, recovery.
- **NorthStar contribution:** separated production, independent assurance, NTV, IV&V, custody, evidence, and verdict.
- **NS3 rule:** no result is accepted until the assurance and custody planes issue correlated evidence.

## First development objective

Eliminate Human-As-API through a durable, observable, authenticated internal communication fabric before any real payload or autonomous task is enabled.
