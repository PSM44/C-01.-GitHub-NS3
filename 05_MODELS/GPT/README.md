# GPT

Model-specific working knowledge for GPT-family models used by NS3.

This domain will contain only verified, versioned operating guidance:

- `gpt.md`: model identity, approved role and operating profile;
- `capabilities.md`: tested capabilities and known limits;
- `configuration.md`: non-secret configuration contract;
- `compatibility.md`: supported tools, interfaces and exclusions;
- `evaluation/`: reproducible evaluations, evidence and decision records.
